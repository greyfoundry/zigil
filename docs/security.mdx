---
title: "Security boundaries"
description: "Handling untrusted data and schemas."
---

Validation is not authentication, authorization or sanitization. Resource limits, strict decoding, deterministic behavior and explicit reference resolution are part of the intended design. Do not implicitly fetch remote schema references or trust arbitrary callbacks from untrusted schemas.

For vulnerabilities use the private reporting procedure in the repository's SECURITY.md. Do not include real secrets in reports.
