---
title: "JSON Schema and OpenAPI"
description: "Planned standards interoperability."
---

Draft 2020-12 is the target dialect. Export and runtime validation of external schemas are separate capabilities. Input and output schemas may differ after transformations. A constraint that cannot be represented must not disappear silently.

OpenAPI 3.1 and 3.2 Schema Objects have dialect-specific semantics. Full OpenAPI document validation is outside the initial scope. No standards conformance is claimed yet. Remote references will not be fetched implicitly.
