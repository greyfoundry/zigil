The baseline is Zig 0.17.1, verified against the official release index and an
SHA-256 checked official Linux distribution. Local tests execute on x86_64 Linux.
The public tests and example cross-compile for aarch64 Linux, x86_64 Windows and
aarch64 macOS. Those builds do not establish native runtime correctness there.

CI is configured for native Linux and Windows and representative cross targets.
Read results for the exact commit before treating a configured target as tested.
The API is experimental, version 0.0.0, with no published release.

SDK SemVer, compiler versions, JSON Schema dialects and OpenAPI versions are
independent. Draft 2020-12 and OpenAPI 3.1/3.2 are maturity targets, not implemented
compatibility claims. Zig 1.0 readiness means minimizing demonstrated migration
cost, not promising source compatibility with an unreleased compiler.
