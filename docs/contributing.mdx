---
title: "Contributing"
description: "Working on Zigil and its documentation."
---

Discuss substantial changes before implementing them. Keep patches focused; explain the approach, run relevant tests and disclose material AI assistance. Human review remains required. Use the [repository contribution guide](https://github.com/greyfoundry/zigil) as the policy reference once published.

The public site source is `docs/`. Run the verified Mintlify CLI from that directory, and review changes before deployment. Private research and agent logs do not belong in the docs.
