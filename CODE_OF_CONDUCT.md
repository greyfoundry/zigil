# Code of conduct

Treat other contributors with respect. Critique code and decisions, not people. Harassment, threats, discriminatory abuse, doxxing and unwanted sexual attention are not acceptable. Respect privacy, differing experience levels and constructive disagreement. Do not pressure maintainers to merge unreviewed work or disclose private information.

These expectations apply in project issues, reviews, discussions and other project spaces. Report problems privately to a maintainer through a published contact channel. Maintainers may remove content, limit participation or ban users in response to harmful behaviour; they should handle reports discreetly, proportionately and without retaliation. A maintainer involved in a complaint should not be its sole reviewer where an alternative exists. No invented contact address is provided in this seed.
